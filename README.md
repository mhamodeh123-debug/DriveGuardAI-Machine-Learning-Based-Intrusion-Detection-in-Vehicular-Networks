# DriveGuardAI-Machine-Learning-Based-Intrusion-Detection-in-Vehicular-Networks
The rising level of connectivity among modern vehicles has significantly increased the level of cybersecurity threats targeting the communication capabilities used among vehicles, with the Controller Area Network (CAN) being the most impacted communication protocol. To mitigate the above challenges, the proposed project will utilize the CIC IoV Dataset 2024, which is a realistic dataset generated based on the communication protocol used among vehicles, namely the CAN protocol, which was collected from a real 2019 Ford vehicle operating under both benign and attacking conditions, including Denial-of-Service (DoS) and spoofing attacks. Under the proposed project, the DriveGuardAI system will be implemented as a machine learning-based intrusion detection system targeting the Internet of Vehicles (IoV) environment, the project will focus on data preprocessing, feature extraction, class imbalance handling, model development, model evaluation, among other steps, with the main objective being the development of multiple machine learning-based models that can efficiently detect any potential threats targeting the CAN protocol used among vehicles. Based on the proposed project, the following are the potential implications that can be derived: The proposed project will significantly contribute to the development of efficient intrusion detection mechanisms targeting the Internet of Vehicles (IoV) environment.
